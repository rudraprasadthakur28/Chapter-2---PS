# Python Chapter 2 — Practice Set

This repository contains my solutions to the **Python Chapter 2 Practice Set**.

The exercises focus on variables, user input, data types, arithmetic operators, comparison operators, and basic mathematical calculations.

## Questions Covered

### 1. Add Two Numbers

Write a Python program to add two numbers.

### 2. Find the Remainder

Write a Python program to find the remainder when a number is divided by `z`.

### 3. Check the Type of a Variable

Write a Python program to check the type of a variable assigned using the `input()` function.

### 4. Compare Two Variables

Use a comparison operator to find out whether `a` is greater than `b` or not.

Given:

```python
a = 34
b = 80
```

### 5. Find the Average

Write a Python program to find the average of two numbers entered by the user.

### 6. Calculate the Square

Write a Python program to calculate the square of a number entered by the user.

## Topics Practiced

* Variables
* Data types
* `input()`
* `int()`
* Arithmetic operators
* Comparison operators
* Addition
* Division and remainder
* Average calculation
* Square of a number
* Basic user-input programs

## Learning Goal

The goal of this practice set is to apply the concepts learned in **Python Chapter 2** through simple programming problems and build confidence with basic Python operations.
